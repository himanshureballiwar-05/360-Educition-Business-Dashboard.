# 360-Educition-Business-Dashboard.
The 360° Education Business Analytics Platform is an interactive Power BI dashboard designed to help educational institutions monitor and analyze business performance across multiple branches. The dashboard provides valuable insights into branch operations, admissions, student performance, revenue, and key business metrics to support data-driven decision-making.

This project demonstrates end-to-end data analytics skills, including data cleaning, transformation, modeling, DAX calculations, and interactive dashboard development.
